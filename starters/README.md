# starters/

arquetipos de webs listas para descargar y modificar. cada starter es **una web completa** que el user puede subir a Neocities tal cual.

ver `ROADMAP.md → Fase 3` para los starters planificados:

- `studio-carta/` — portfolio tipo meowrhino / rikamichie
- `one-pager/` — scroll narrativo vertical
- `archivo/` — índice cronológico (blog/diario)
- `collage-ventanas/` — estética 2000s con ventanas drag

ver `DESIGN.md → estética de los starters` para las directrices visuales de cada uno.

cada starter debe traer:
- un `index.html` y los archivos necesarios
- un `README.md` explicando cómo personalizar
- su propio `style.css` (puede sobrescribir las `--r-*` vars)
- los componentes que necesite, copiados en `/components/` local
